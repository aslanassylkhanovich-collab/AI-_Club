## 3. Выполненные этапы и программные решения (по программе Урока 3)

### Этап 1. Загрузка и первичный осмотр данных
- Исходный файл: `krisha_astana_esil_nura_2026.csv`
- Размерность: **750 строк**, **19 столбцов**.
- Проверка структуры: `df.info()`, `df.head()`, `df.describe()`.
- Исходный датасет сохранен в неизменном виде в переменной `krisha_data`, все операции производятся на копии `krisha_df = krisha_data.copy()`.

### Этап 2. Очистка данных и удаление признаков
- Проверка дубликатов по URL: `krisha_df.drop_duplicates(subset=['url'])`.
- **Задание 2 из урока 3 (функция `delete_columns`)**:
  ```python
  def delete_columns(df, col=[]):
      for c in col:
          if c not in df.columns:
              return None
      return df.drop(col, axis=1)

  cols_to_remove = ['url', 'price_text', 'price_is_from', 'room_count', 'city']
  krisha_df = delete_columns(krisha_df, cols_to_remove)
  ```
  Удалены неинформативные признаки (город и комнатность константны, URL и текстовая цена не требуются для модели).

### Этап 3. Feature Engineering: математические операции
1. **Задание 1 из урока 3 (Квадрат цены)**:
   ```python
   price_square = krisha_df['price'] ** 2
   ```
2. **Цена за квадратный метр (`Price_m2`)**:
   ```python
   krisha_df['Price_m2'] = (krisha_df['price'] / krisha_df['area']).round().astype(int)
   ```
3. **Отношение этажа к этажности (`FloorRatio`)**:
   ```python
   krisha_df['FloorRatio'] = (krisha_df['floor'] / krisha_df['floor_count']).round(2)
   ```
4. **Категория этажа (`FloorType`)**:
   ```python
   def get_floor_type(row):
       if row['floor'] == 1:
           return 'первый'
       elif row['floor'] == row['floor_count']:
           return 'последний'
       else:
           return 'средний'

   krisha_df['FloorType'] = krisha_df.apply(get_floor_type, axis=1)
   ```
   *Вывод*: средние этажи торгуются на **4.2% дороже** первого этажа.

### Этап 4. Работа с датой и временем (datetime)
- Преобразование даты в формат datetime:
  ```python
  krisha_df['date'] = pd.to_datetime(krisha_df['date'])
  krisha_df['YearSale'] = krisha_df['date'].dt.year
  krisha_df['MonthSale'] = krisha_df['date'].dt.month
  krisha_df['WeekdaySale'] = krisha_df['date'].dt.day_of_week
  krisha_df['DayName'] = krisha_df['date'].dt.day_name()
  ```
- **Возраст здания (`AgeBuilding`)**:
  ```python
  krisha_df['AgeBuilding'] = krisha_df['date'].dt.year - krisha_df['construction_year']
  ```
  *(по аналогии с формулой `AgeBuilding = Date.dt.year - YearBuilt` из урока 3)*.
- **Задания 4 и 7 из урока 3 (функция `get_weekend` и анализ выходных)**:
  ```python
  def get_weekend(weekday: int) -> int:
      return 1 if weekday in (5, 6) else 0

  krisha_df['Weekend'] = krisha_df['WeekdaySale'].apply(get_weekend)
  weekend_count = (krisha_df['Weekend'] == 1).sum()
  ```
  *Результаты*:
  - Количество объявлений в выходные (`weekend_count`): **219** (29.2% выборки).
  - Средняя цена в выходные: **29 948 858 ₸**.
  - Средняя цена в будние дни: **30 280 778 ₸**.

### Главные инсайты:
1. **Премия за локацию**: Средние площади 1-комнатных квартир идентичны (~42 м²). Вся разница в цене обусловлена престижем района и инфраструктурой Есильского района (Экспо, Байтерек, набережная, бульвар Нуржол).
2. **Материал стен**:
   - Кирпичные дома: максимальная стоимость (до **805 тыс. ₸/м²** в Есиле и **713 тыс. ₸/м²** в Нуре).
   - Монолитные дома: составляют более 80% рынка (**759 тыс. ₸/м²** в Есиле, **680 тыс. ₸/м²** в Нуре).
   - Панельные дома: встречаются только в Нуре и являются самыми бюджетными (**595 тыс. ₸/м²**, чек ~25 млн ₸).
3. **Возраст дома**:
   - Новостройки 2024–2026 гг. стоят в среднем **31.3 – 32.8 млн ₸** (~750–789 тыс. ₸/м²).
   - Дома 2016 года постройки продаются в среднем по **25.5 млн ₸** (~622 тыс. ₸/м²). Премия за свежую постройку составляет **+26.8% к цене за м²**.

   - *Есиль*: Highvill Ishim (~885 тыс. ₸/м²), Akbulak Riviera (~860 тыс. ₸/м²), Croco (~820 тыс. ₸/м²), Qasteev (~805 тыс. ₸/м²).

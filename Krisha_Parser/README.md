# Парсер квартир Krisha.kz

Сбор объявлений из выдачи без открытия страниц квартир и без координат.

## Запуск

Если Jupyter уже установлен, откройте `krisha_listings.ipynb` в этой папке.
Парсер `krisha_parser.py` должен лежать рядом с тетрадкой.

Если Jupyter нет, установите Python 3 и выполните в терминале macOS:

```bash
cd ~/Desktop/Krisha_Parser
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m jupyterlab
```

В Jupyter откройте `krisha_listings.ipynb` и запускайте ячейки сверху вниз
с помощью **Shift+Enter**. При последующих запусках достаточно перейти
в эту папку, активировать `.venv` и выполнить `python -m jupyterlab`.

## Как поменять город

В ячейке с настройкой замените название:

```python
CITY = "Шымкент"
```

Доступны: Алматы, Астана, Шымкент, Актобе, Караганда, Тараз, Атырау,
Усть-Каменогорск, Павлодар, Кызылорда, Семей, Костанай, Кокшетау, Актау, Уральск,
Петропавловск, Туркестан, Талдыкорган, Экибастуз.
После изменения города снова выполните эту ячейку и все следующие.
У каждого участника своя копия папки; код парсера менять не нужно.
Если парсер уже был импортирован до обновления файлов, перезапустите ядро
(Kernel → Restart Kernel) и выполните ячейки заново.

## Как запустить сбор по всему городу

После выбора `CITY` запустите ячейку сбора без ограничения `max_ads`:

```python
from krisha_parser import parse_krisha_listings

csv_path = parse_krisha_listings(CITY)
```

Именно такой запуск уже стоит в тетрадке. Если раньше пробовали
`max_ads=100`, уберите этот параметр и снова выполните ячейку.
Сохранённые объявления будут пропущены, новые добавятся в тот же CSV.

По умолчанию парсер перебирает страницы с 1-й по 3000-ю. Он остановится
раньше при пяти пустых страницах подряд, повторении предыдущей страницы
или блокировке сайта. Это сбор без лимита количества объявлений,
но не гарантия получения всех объявлений города.
Дождитесь итогового сообщения, затем запускайте ячейку загрузки CSV.
Во время сбора компьютер должен оставаться включённым, а Jupyter — работать.

## Пробный сбор 100 объявлений

Для пробного сбора замените строку запуска на:

```python
csv_path = parse_krisha_listings(CITY, max_ads=100)
```

Это лимит **новых** объявлений за запуск; для сбора по всему городу
используйте пример выше без `max_ads`.

## Результат

CSV появится рядом с тетрадкой: например, `krisha_shymkent_listings.csv`.
Он сохраняется после каждой страницы. При повторном запуске уже сохранённые
URL пропускаются. Чтобы остановить сбор, нажмите кнопку остановки ячейки.
При блокировке сайта парсер также остановится, сохранив собранное.

Описание сокращённое (`information_preview`). Этажность и потолки заполняются,
если указаны в карточке. `price_is_from=True` означает цену «от».
Из-за изменений выдачи сбор всех объявлений не гарантируется.
